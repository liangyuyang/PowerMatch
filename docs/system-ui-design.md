## 1. 产品定位与已确认界面

核心问题：同一个设备，采用不同电源、储能与工作策略，在指定室内光照下，能正常运行多久？同时回答首次停机原因、无光续航、周期收支、峰值供电能力，以及达到目标所需的最小光伏面积/储能/工作频率。

用户已选择保留首轮界面1和界面3：界面1作为主演算台，界面3作为方案对比页。二者共享同一套数据，可随时切换；界面2作为历史探索保留。不是两套独立应用，也不要求重复输入。

光伏是能量来源；电池、EDLC、LIC是不同储能；LDO、采能PMIC及电源切换属于供电路径。三种入口为“单独电池”“纯室内光伏”“室内光伏＋储能/备用电池”；电源管理独立可选。

结果分为“电气条件不满足”“资料不足”“条件估算”“已与实测校准”。一周能量有盈余仍可能因周末或峰值欠压停机。仿真未中断时写“所设365天内未中断”，显示老化范围，不输出无条件永久续航。

## 3. 科技极简视觉与交互规范

白底、深色正文、细分隔线、大留白；品牌蓝来自原版ZenMeasure Logo。建议色板：品牌#100080、正文#172033、辅助文字#475569、边框#CBD5E1、浅底#F8FAFC、编辑蓝#1D4ED8、警示#92400E。正式实现再逐项测对比度。

正文14–16px，标签12–14px，关键结果28–40px；10px为绝对下限，不作为常用字号。PDF正文11–12pt，辅助字不低于10pt。正常文字对比至少4.5:1，控件/图形状态至少3:1；颜色之外同时使用图标和文字。小屏纵向布局，不整体缩小桌面。

| 输入状态 | 表现 | 行为 |
| --- | --- | --- |
| 默认/继承 | 中性浅灰底、深色字、“默认/继承” | 可编辑；复制来源成为比较基线 |
| 已修改 | 浅蓝底、蓝边、编辑图标、“已修改” | 显示旧值；可逐项恢复或全部恢复 |
| 计算值 | 计算图标、只读 | 展开公式与来源 |
| 待核验 | 琥珀提示 | OCR成功不自动变成工程通过 |
| 不兼容 | 红色图标＋原因 | 点击定位参数，提出可执行修改 |

标准单位相同的值不算变化，例如1000µA与1mA；改回基线后移除已修改标识。库的新默认值不静默覆盖旧设计。建议折叠“工程详情”，保持第一屏只展示影响当前结论的字段。

横版蓝Logo：应用顶栏、登录邮件、PDF封面；突出式Logo：启动页/应用标识；灰版：PDF页脚。保持比例，使用原图，不重绘或拉伸。AI视觉稿只用于排版参考，正式应用与PDF嵌入原版品牌资产。

模态框有关闭按钮并支持Escape与遮罩关闭；菜单支持Escape/点外关闭，尽量返回触发器焦点。关闭浮层保留未保存输入，丢弃是独立动作。日期编辑固定YYYY-MM-DD并在保存前规范化。动画可暂停、支持减少动画；键盘与表单可完成等价画布操作。

## 4. 演算台与对比页

主演算台保留左输入、中供电链、右结果、底部曲线的结构。光线与电流采用不同线型；游标推进时同步光照、充/放电、冷启动、欠压和负载状态。一次电池只有单向流出；有充电能力的储能才允许受控回充。

点击元件打开参数区：型号、能力、默认差异、来源Spec、替换型号、相关讨论。纯光伏不显示虚构的储能支路。能量框图和引脚级原理图分别命名。

对比默认3列，可选2–4个方案；更多方案分页。共同锁定设备修订、光照、环境、起始时间和初始储能。解除锁定时显示“比较条件不同”。比较顺序为电气兼容、首次停机、无光续航、面积/储能、收支/损耗、体积/成本（资料齐全时）。修改方案后，旧比较标为过期。

图表可切换设备电流周期、储能电压/SOC、供电连续性、损耗明细。无完整数据时显示已知波形/日程与缺项，不以36小时等概念数字冒充实际结果。显示仍可见与设备仍在测量/广播分开呈现。

## 5. 硬件、方案、修订与分享

对象层级：硬件项目→设计方案→不可变修订→演算结果。例如MOT-U125下有“现售LR41”“纯光伏＋1.5V LDO”“光伏＋LIC”“CR2032＋稳压”；各方案都有自己的r1/r2。

修订锁定设备负载版本、所有元件/Spec、拓扑、策略、光照、初始状态、单位、假设、引擎版本和输入哈希。结果引用这份快照。新Spec只提示更新，用户接受后生成新修订并重算，不改变历史结论。

复制公开案例形成新的所有权，保留来源项目/方案/修订及署名，不复制原作者权限、私密讨论和未经授权的附件。官方案例对外只读。被引用设备和元件采用归档；修改资料留记录，不能直接抹除历史引用。

草稿自动暂存；保存修订、发布公司、发布大厅分开。员工个人案例默认只自己可见，可以同时向公司及大厅发布选定修订快照。公司默认只读＋复制，不隐含共同编辑；多人共同编辑可后续单独设计。撤回公开不保证他人已下载/复制的内容消失。

## 6. 身份、空间与唯一管理员

仅精确匹配已验证邮箱@后的miaomiaoce.com、zenmeasure.com、zenmeasure.space。前导点不属于邮箱域名；含相似字符串的域和任意子域不自动成为员工。

| 外部已登录 | 仅公开大厅，管理自己的内容 | 无 | 无；可提新版本建议 | 可以，显示贡献来源 | 无 |

| patrick@miaomiaoce.com | 同员工 | 同员工 | 管理权限 | 可以 | 唯一管理员 |

员工的元件审核入口位于元器件库，不等于进入/admin。管理员由服务端已验证用户ID绑定唯一邮箱；前端传入邮箱不得赋权；不提供一般的“新增管理员”按钮。角色与论坛等级无关。

游客草稿可在浏览器保存；服务端不提供隐藏的长期个人空间。匿名公开案例以安全Cookie/管理凭据管理，公开URL不带编辑权，丢失凭据不承诺恢复。外部邮箱登录可跨设备管理其公开案例。

所有读取、搜索、复制、评论、附件、导出和任务统一检查对象权限。私密响应不进入公开缓存；公司权限撤销后，订阅也不能泄露公司标题/附件。管理员不默认日常查看所有私信和私人设计，需要处理滥用时采用有审计的支持流程。

Magic Link：短效高熵单次Token，只存哈希、原子消费；GET落地页不直接消费，继续登录动作兑换，防邮箱扫描器。Cookie为HttpOnly/Secure/SameSite；校验跳转白名单、CSRF及请求限流。登录证明身份，授权在敏感请求中重新判断；停用员工/撤销会话立即生效。

大厅名称“穿山甲Tiny”，产品型号ZenMeasure MOT-U125。已收录用户提供的整机彩页v2.1/2026-06-16。它不能替代内部MCU/LCD芯片的电气和引脚规格书。

按9s和1.2s顺序相加，周期10.2s；平均电流=(3×9+90×1.2)/10.2=13.2353µA，显示13.24µA。若负载电压恒1.5V，平均功率约19.85µW，工作段135µW。“时序计算”和“直接输入平均电流”是互斥模型，经验11+µA单列，不修改时序凑值。

纯光伏无缓冲时，在实际所需电压处需满足约90µA工作电流＋LDO自耗＋余量；Voc或Isc足够均不能单独证明可用。有缓冲则同时验证平均补能和峰值压降，不要求PV始终独自承担完整峰值。

LDO候选TI TPS7A02的1.5V输出版本：系列典型Iq25nA、输入1.5–6V；需核对具体订购型号、压差、启动过冲、温度和输出电容。输入1.5V不等于稳压输出1.5V，需输入余量。若1.65V为芯片上限，应在此限制内校核，不能因1.8V才鬼影就容许超过芯片上限。[TI TPS7A02](https://www.ti.com/product/TPS7A02)

大厅分为现售电池型产品参考与光伏改型方案。LR41×2不默认两串直连芯片；150lux不变成所有光伏的通用门槛；8个月不作为改型结果。模板可演示已知电流周期与日程，真实续航仍需物料参数。

## 9. 秒秒测微光能温湿度计 / MHO-C404

正式名称替换“老米3”。已收到彩页v1.1/2026-09-07，采用彩页黑色产品外观；原白色照片只留历史参考，不作为MHO-C404的正式照片。

彩页参数：透明PC；56.2×56.2×12.8mm；净重32g；额定DC3V；BLE5.0；空旷30m；温度0～60°C、±0.5°C、分辨率0.1°C；湿度0～99.9%RH、±5%RH、分辨率0.1%RH；支架/磁吸。测量范围不自动等同全部元件工作环境范围。

彩页明确薄膜光伏＋电容储能＋电子墨水屏，广播间隔随剩余电量变化。未提供PV材料/型号、储能类型/容量、裸屏料号/驱动波形、刷新能耗、PMIC或广播策略表。不能把“薄膜”推断成OPV/钙钛矿，把“电容”推断成LIC，或把整机DC3V当裸屏驱动电压。

显示库分产品外观、显示模组、驱动负载模型三层。当前创建两个产品绑定展示条目，裸屏料号待补。Tiny预览温度、低压不可见/鬼影；MHO-C404预览温湿度、表情、低电提示和刷新。

LCD断电视觉按实际响应校准；电子墨水屏断电保持最后画面，标明数据陈旧，不能显示为“仍在测量”。视觉效果为示意，不宣称光学仿真。分别输入维持电流或单次刷新能量/持续时间、驱动电压、温度依赖；整机总电流已含显示时不再叠加。

MHO-C404增加自适应策略表：电量区间、广播/测量/刷新间隔、恢复门限，实际阈值待补。比较固定与自适应策略时，同时给出有效测量/广播次数、最长数据延迟，避免以停止业务换“长续航”。

## 10. 元器件库与Spec治理

电池首批覆盖LR41、LR44、CR2032、CR2450、CR2477、AAA/7号、AA/5号。标准分类码与厂家订购型号分开；同CR2032不同厂商保留独立容量/曲线。具体起始研究见component-catalog-research.md，不把候选清单冒充完整生产数据库。

## 11. 默认器件与1F LIC

通用电池默认CR2032、1串1并；Tiny原产品保持LR41×2并提示连接待核对。切到LIC时，电容默认1F。默认只代表设计起点，不代表经过验证的BOM。

已核实CAP-XX LIC：LY13R808014M106R-L 10F、LY13R808020M256R-L 25F、LY13R808025M306R-L 30F等。原厂现行链接Spec v1.7/2024-08；10F型号窗口2.5–3.8V、DC ESR800mΩ、120小时条件漏电上限3µA。不能用AC ESR替代DC ESR或将10F数值线性缩成1F。[CAP-XX LIC](https://cap-xx-assets.s3.eu-west-2.amazonaws.com/CAP_XX_LY_13_R8_LIC_Datasheet_V1_7_b24dfbf553.pdf)

本轮未核实到有完整原厂Spec且满足要求的1F LIC，因此默认标“自定义LIC · 1F · 型号待匹配”；电压/漏电/ESR缺项显式显示。允许带假设的敏感性分析，或换到真实10F型号完整继承其参数。普通1F EDLC不能标成LIC。

数学示例：假设理想1F在3.8–2.5V间可用，负载1.5V/13.2353µA，可用能量4.095J；100%理想转换约57.3小时，理想LDO按C×ΔV/I约27.3小时，均未计漏电/压差/老化。不是某款1F LIC的实测，也不是MHO-C404参数；说明相同F数不能脱离供电路径谈续航。

## 12. 光源、默认日程与计算原则

默认办公室复合照明、260lux、每周5天、每天10小时、法线夹角0°。建议具体日程周一至周五09:00–19:00，可改星期/时段/假日/时区：50小时有光、118小时无光、最长连续无光62小时。

预设含办公室复合照明（顶部灯＋散射/可能日光）、LED暖白3500K/中性4000K/冷白6500K、家庭复合照明、办公室荧光灯、窗边混合日光、实测lux/光谱序列。办公室混合是场景模板，不是统一光谱；光源组成和占比可编辑，色温也不能唯一确定光谱。

Lux为视觉加权量，没有适用于所有PV/灯的统一lux→µW/cm²常数。优先同光谱下Pmpp/Vmpp/Impp随lux曲线；混合光源未标定时标“光源近似”。150lux记录只有在原测试组合中成立。

角度为光线与板面法线夹角，0°垂直入射；方向光可按max(0,cosθ)近似，漫射分量另算。若lux是在当前板面实测，不再乘cos，避免双重折减。有效面积、边框、封装透光损失与遮挡分开。

负载采用互斥整机模式或分模块事件，禁止双算休眠/总电流。事件有电流/功率、持续时间、频率、电压依赖及启动能量。短事件检查峰值/启动，长时推进光照、SOC和老化，不能用周平均掩盖脉冲。

有MPPT按采能/转换效率曲线；无MPPT直连或LDO按PV I-V与负载交点，不假设获得100%Pmpp。LDO路径按输入电流与压差损耗建模。

电容可用能量为∫VC(V)dV，常数C时0.5C(V高²−V低²)；加入ESR×I、漏电、自放电、温度、初始电压、均衡损耗和老化。LIC不得当EDLC放到0V。电池用原厂负载/温度/截止/脉冲曲线，mAh不是独立于条件的常数。

串联增加电压、同串Ah不增加；并联增Ah须符合化学/一致性/保护条件。一次电池禁止回充，混合型号/SOC无有效拓扑不直接允许。每步保存采能、负载、转换损失、漏电、弃能及储能变化，检查能量守恒。
