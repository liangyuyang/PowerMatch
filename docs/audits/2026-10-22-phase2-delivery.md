# PowerMatch 第二批：交互与性能

设备 Home PC / HomePC；项目 D:/Data/GitHub/PowerMatch，main。用户以“继续”授权延续已批准审计计划。本批由主代理实施，没有启动新的子 Agent。生产版本及 Worker ID 以 HANDOFF.md 最新发布记录为准。

## 已实现

- 元器件创建与 Spec 候选审核共用结构化参数表单，覆盖电池、可充电电池、LIC、超级电容、PV、LDO、PMIC 和显示模组。字段带单位；未知保持空值；高级 JSON 保留额外字段与完整精度，非法结构不能提交。通用被动元件仍通过高级参数定义，不编造未有资料的字段单位。
- 新表单、气泡、图表标题和主要新操作支持七语言；元器件数值和图表提示最多两位小数，微小电流使用 nA。原始参数不被显示格式改写，原厂说明保持原文。
- 页面 URL 支持刷新与浏览器前进/返回。案例和指定修订可复制分享链接；链接打开前提醒保存当前草稿，原权限在服务端执行，私有链接不会变成公开数据。
- 从比较快照继续设计会建立独立草稿，员工默认个人空间，保存不会覆盖此前工作台关联的案例。
- 大厅每页 24 项、游标继续加载，排序包含稳定 ID；查询先执行权限范围再分页。元器件库先渲染 24 张卡片，搜索仍覆盖完整目录。目录通过 ETag 验证变化；所有 API 仍 no-store，仅复用公共目录响应体，不缓存会话、个人或公司数据。目录查询本身仍会执行，不宣称减少 D1 查询次数。
- 普通请求有超时；等待写入超时时明确结果可能已发生，不能默默重试。切换大厅/论坛/后台会取消旧读取，大厅分页与规格列表用序号阻止迟到响应覆盖新内容；切换身份清除对应表单/规格状态。元器件加载有独立进度，公共 busy 计数不再被较早结束的并发操作提前清除。
- 仅内容哈希构建资源位于 /bundles/ 并长期 immutable 缓存，入口与版本文件重新验证；原始品牌/产品素材没有套用永久缓存。图表 memo 避免无关表单状态变化时重复渲染，各图表渐变 ID 独立。
- 可见关闭、Escape、背景点击保留表单输入；修复背景点击关闭后浏览器默认焦点落到空白处的问题。

## 验证

- 105 项单元测试，含新增未知值/完整精度/非法 JSON、分享链接不带认证参数、游标/权限、目录 ETag、请求取消及写超时不重试。
- 48 项隔离 D1 API 断言、上一批草稿/身份/版本冲突浏览器回归，以及默认输入/图片比例/角度控件/气泡桌面与手机回归通过。
- 第二批浏览器验收：前进/返回/刷新保留设计；参数与高级字段互通；非法数据禁用提交；三种关闭方式与焦点/草稿；比较副本保存为不同 private case；指定修订链接、关闭保留草稿、访客拒绝私有链接；24 张库卡片/全目录搜索；范围请求竞态/继续加载；日语气泡、390px 无横向溢出及无页面异常。
- 生产构建在隔离本地 Workers 运行，通过 CSP、图表/AI 面板延迟加载、品牌 PDF 与移动布局检查。没有真实 AI 调用、发邮件或生产登录账号操作；登录测试均为本地合成身份。
- 手动浏览器检查 PV 参数编辑：可见关闭及 Escape 返回触发按钮，重新打开保留输入；背景点击的焦点修复另有自动化断言。截图见本目录 2026-10-22-parameters.png。

## 性能证据及边界

脚本 scripts/measure-ui.mjs；原始样本见 2026-10-22-phase2-performance.json。Home PC / Edge headless / 本地 Workers；桌面 1440×1050，移动视口 390×844 使用 4 倍 CPU 减速。每种冷/暖缓存各 3 次。不是物理手机或真实用户 p75，也不是网络测速。流程包含初始曲线、四个 30 天方案、工作台切换到 365 天。

| 场景 | 修改前页面就绪中位数 | 修改后页面就绪中位数 | 修改后实验室 LCP 中位数 | 修改后 365 天输入至绘制中位数 |
| --- | ---: | ---: | ---: | ---: |
| 桌面冷缓存 | 345ms | 368ms | 244ms | 67ms |
| 桌面暖缓存 | 195ms | 157ms | 76ms | 57ms |
| 移动视口冷缓存 / CPU×4 | 1937ms | 1722ms | 940ms | 310ms |
| 移动视口暖缓存 / CPU×4 | 974ms | 1023ms | 284ms | 189ms |

CLS 约 0.034（桌面）/0.038（移动）。样本波动明显，不把中位数变化解释为已证实的速度提升。多图表流程仍记录到约 0.6–1.0 秒长任务；不能声称达到真实 INP≤200ms。当前主入口与图表分块仍较大，下一步应将长计算移到后台线程、按可见区域安排比较图表渲染，并对交互阶段单独做 trace/真实手机验证。本次没有假装取得未提供的 Chrome DevTools MCP trace。
