## 已交付

1. 1 天未耗尽不再被解释为可覆盖 62 小时暗期；网页和 PDF 共用“已覆盖 / 有缺口 / 未证明”的判断。
2. 直接连接不再计入不存在的稳压器静态电流和采能转换损耗；引擎版本升为 0.1.1。
3. 员工新方案和复制方案默认“仅自己”；已有明确保存范围保持原值。
4. 刷新草稿保留案例、父修订、预期版本和范围。冲突或读取失败不覆盖输入；可重试或另存安全副本。
5. 会话失败不降为访客；多标签页切换账号时，前后端同时阻止错身份保存/删除。
6. 网页、接口及错误响应增加安全头；普通 JSON 上限 128 KiB；PDF/上传/AI 各用独立上限；计算和元件创建采用原子限流。
7. 更新 Hono/Vite/Wrangler，全量依赖审计当次为 0 个已知漏洞。保留 Cloudflare 已启用的性能统计，仅允许其官方脚本域名；应用不允许内联或动态执行脚本。
8. 实际 PDF 检查发现并修正长来源链接截断、页面灰底和参数超长小数；小电流使用 nA，完整精度保留在设计 JSON。
