2026-09-12：用户已选择首轮方案1和3，分别作为主演算台和并列对比页，共享同一套项目、方案与修订数据。

- [主演算台](v2-workbench.png)：编辑参数、查看供电链和当前已知负载波形。
- [方案对比](v2-comparison.png)：相同设备/光照下并列比较电池、纯光伏、光伏＋LIC；缺少参数时明确待计算。
- [Patrick专用Admin](v2-admin.png)：以Spec原文与候选字段核对为主，兼顾来源、权限与处理队列。

PNG是静态视觉设计，不是已实现的交互应用。供电连接图是系统框图，芯片图形不代表真实封装/引脚。12cm²为构图中的面积示例；1F为用户要求的LIC默认值，真实型号待匹配；09:00–19:00为可编辑日程建议。62小时表示该日程的最长无光期，不表示储能续航。Admin的计数与状态用于展示布局，不代表线上数据。

颜色和状态以系统设计文档为准：默认/继承为中性灰，用户改动为蓝色并配文字，派生结果只读，缺项为琥珀色。最终实现嵌入原始Logo及经过核对的产品图片，不从生成图片中提取品牌字样。

语言入口保持在顶栏：跟随浏览器/设备语言＋七语手动选择。手动选择记忆，登录账户可同步；不改变电气参数和单位。设计图以简体中文呈现。

01.png、02.png、03.png为首轮探索留档，其中示意续航数字不作为工程结论。新版以v2图及最新系统文档为准。
