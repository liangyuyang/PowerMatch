# 品牌、产品与Spec素材

brand目录的三张ZenMeasure Logo保留用户原始图像，供顶栏、邮件、PDF及应用标识选用。

specs目录保存用户提供的原始整机彩页：MOT-U125 v2.1 / 2026-06-16，以及MHO-C404 v1.1 / 2026-09-07。彩页用于产品信息；不视为内部芯片、裸屏或供电电路的完整电气规格书。

products/MOT-U125-body-white.png：根据用户提供的Tiny产品渲染图，经图像编辑去除外露探针导线，仅保留本体，白色背景。

products/MHO-C404-body-white.png：根据新提供的MHO-C404彩页制作产品本体白底素材。采用彩页的黑色正面和铜色边框；此前白色产品照片不作为MHO-C404正式外观。

两张产品图为经过生成式图像编辑的展示素材，不是尺寸计量依据，也不宣称像素级无损裁切；背景为白色，不是真透明通道。原始彩页保留供核对。Tiny去线只用于UI简化，原产品仍有探针。

第三方元器件原厂PDF保存在本机研究目录，下载来源/文件哈希见../spec-download-manifest.json。公开代码许可不自动适用于品牌、产品图片及厂家Spec；文件分发策略在系统设计文档中单独规定。
